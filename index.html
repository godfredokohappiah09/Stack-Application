What the stacks just did

    Why the stack is important in this app

    • Latest first. Undo must reverse your most recent action, not an old one. A stack always gives back the last item added, so this happens automatically.
    • Step by step history. Pressing undo again and again walks back through every action in the exact reverse order.
    • Redo needs a stack too. Each undone action is pushed onto the redo stack, so it can be brought back in the right order.
    • A new action clears redo. Once you do something new, the old future no longer applies, so the redo stack is emptied.
    • Fast. Push and pop only touch the top, so undo stays quick however long the history is.

    The stack code behind the app

    class Stack {
  constructor() { this.items = []; }
  push(x)     { this.items.push(x); }       // add on top
  pop()       { return this.items.pop(); }  // remove from top
  peek()      { return this.items[this.items.length - 1]; }
  isEmpty()   { return this.items.length === 0; }
  size()      { return this.items.length; }
}
